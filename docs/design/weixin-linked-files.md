# 微信本地报告链接交付

本次范围来自用户要求：助手回复中的本机报告链接在微信无法打开，需要转成微信可以接收和阅读的文件。沿用现有发送通道、会话归属、共享输出确认记录和结束通知，不引入服务器、公开下载地址、数据库或新依赖。

`BridgeCoordinator.resolveOutputWorkspace` 提供当前会话工作目录。`WeixinLinkedFiles` 独立负责收集最终答案中的显式 Markdown 文件链接，在轮次完成后检查真实路径、类型、大小和数量，制作私有临时快照，并通过已有 `sendMediaWithRetry` 发送。按用户要求，Markdown 快照保留原始 `.md` / `.markdown` 扩展名及字节内容，不改编码、不添加 BOM、不转换为 TXT。临时文件在发送返回后清理，原文件保持不变。

普通回复和桌面输出观察器使用同一个交付模块。共享附件使用现有按微信会话、桌面绑定和轮次隔离的 checkpoint，记录路径的命名空间 Hash；只有上传确认成功才落盘，失败的文件允许之后重试。停止/退出后不启动后续上传；已在途且成功的上传仍记入确认。文本比较及分段机制保持不变，避免格式转换重新引入重复正文。附件失败提示与原有结束/耗时提示分离。

只读取工作目录内、非隐藏、非凭据、普通报告格式文件；路径越界、符号链接逃逸、超限和不存在的文件都不自动发送。远程网页不下载，代码与代码块里的示例链接不处理。不改变原生 Provider 文件交付协议。`weixin_bridge_runtime.ts` 既有文件已超过 1000 行，本次仅保留接线代码，解析、验证和快照交付全部放在独立模块，避免扩大本次范围。

验证对应 `test/runtime/weixin_linked_files.test.ts` 和 `test/runtime/weixin_linked_files_runtime.test.ts`：中文路径、空格、括号、file URL、PDF 原字节、Markdown 全文、代码排除、路径边界、大小数量、失败重试、重启去重、退出取消，以及独立/共享两种发起方式和结束耗时通知。真实手机文件预览仍需客户端验收；macOS 自动化结果不能替代 Windows/WSL 实机验收。
